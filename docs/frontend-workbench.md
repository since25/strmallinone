# 前端工作台说明

状态：已实现  
日期：2026-10-04  
依据：当前 React + Ant Design 前端实现  
适用范围：搜索结果选择、单条转存、批量转存和任务状态查看

## 搜索结果

- 搜索结果默认每页显示 20 条，可切换到 50、100 或 200 条。
- 表格选择菜单提供“全选搜索结果”“反选搜索结果”“清空选择”。全选会覆盖当前搜索返回的全部结果，不受当前页限制。
- 选择结果后，页面会显示已选数量。单条转存要求只选择一条资源；批量转存支持一条或多条资源。

## 批量转存

批量转存提交到 `POST /api/batches/transfer`，页面会轮询批次和批次项状态。批次状态、成功/跳过/失败数量显示在右侧；失败项支持查看任务和重新提交。

## 手动转存

手动 115 分享文本仍通过 `POST /api/tasks/manual-transfer` 提交，媒体类型和任务日志入口保持不变。
